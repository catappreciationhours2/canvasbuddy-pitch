Pitch deck for GitHub Pages.
1. Copy speedart.mp4 and session.mp4 (from make-video.sh) into this folder.
2. ./deploy.sh            (or: ./deploy.sh my-repo-name)
No terminal? Make a public repo on github.com, upload these files (index.html, .nojekyll, the videos),
then Settings -> Pages -> Deploy from a branch -> main / (root).
In Google Slides: select text or a shape -> Insert -> Link -> paste the URL. Add #slide=7 to open on the video slide.
Keys: arrows to move, F fullscreen, N notes, E sets the QR link (the QR slide also accepts ...#slide=9&url=http://...).
